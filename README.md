# 푸리와 함께하는 디지털 탄소 다이어트

임직원 참여형 ESG 캠페인 웹 플랫폼

메일 정리, 클라우드 정리, 화상회의 비디오 끄기 등 **디지털 탄소 감축 실천**을 기록하면,
나무 요정 캐릭터 **«푸리»** 가 성장하는 다마고치형 웹서비스입니다.

> 2026 프로젝트형 일경험 · 팀 다온 · ESG 경영과 캠페인 프로젝트

---

## 주요 기능

| 화면 | 내용 |
|---|---|
| 🏠 나의 실천 | 개인 목표 설정 · 오늘의 미션 3종 · 탄소 계산기(15개 항목) |
| 🏢 부서 현황 | 부서별 달성률 순위 · 전사 대시보드 · 푸리의 숲 |
| 🎁 푸리 도감 | 실천 유형별 캐릭터 9종 · 희귀/시즌 아이템 10종 |
| 📰 ESG 소식 | 환경일보 최신 기사 자동 연동 · 사내사례 · 실천팁 |

- 캐릭터 성장 5단계, 표정 8종, 상태 게이지 4종
- 감축량을 «소나무 N그루»로 환산해 체감도 향상
- 개인 기록은 브라우저(localStorage)에만 저장 — 외부 전송 없음

## 기술 구성

- **단일 HTML 파일**, 외부 라이브러리 0개
- 캐릭터를 이미지가 아닌 **16×16 문자 격자 → SVG 실시간 렌더링**
- 웹폰트(림글)를 파일에 내장 — 서버 없이 파일 하나로 동작
- PC 우선 + 모바일 반응형, 접근성 라벨 적용

### 폴더 구성

```
index.html                  완성본 (폰트 내장)
netlify.toml                Netlify 서버 기능 설정
netlify/functions/news.js   환경일보 RSS 수집 (자동 갱신)
assets/fonts/OFL.txt        폰트 라이선스
```

## ESG 소식 자동 갱신

`netlify/functions/news.js` 가 환경일보 RSS를 읽어 최신 기사를 전달합니다.
서버 기능을 사용할 수 없는 환경에서는 섹션 안내 카드로 자동 대체되어 화면이 깨지지 않습니다.

- 갱신 주기 : `CACHE_SECONDS` 값으로 조절 (기본 1시간)
- 다른 언론사로 변경 : `FEEDS` 의 주소만 교체
